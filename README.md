# Shohoj Seba - Local Service Finder

## Project Description

Shohoj Seba is a local service marketplace application that connects customers with nearby service providers such as plumbers, electricians, cleaners, AC technicians, drivers and home tutors.

## Milestone 1

This milestone contains:

- Wireframe Diagram
- Database Schema Diagram

## Main Features

- User registration and login
- Service provider profiles
- Service category browsing
- Search and filtering
- Booking system
- Quotation system
- Rating and review
- Favourite providers
- Notifications
- Service history
- Automatic service reminder

## Database Entities

The schema includes:

- Customer
- Provider
- Admin
- Category
- Service
- Booking
- Appointment
- Quotation
- Review
- Favourite
- Notification
- Availability
- Service Reminder
- Service History
